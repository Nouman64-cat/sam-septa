# SAM-SEPTA Scraper Client

This is the Next.js frontend for the SAM-SEPTA Scraper.

## Quick Setup

**1. Create your Environment File**
Copy the example environment file to `.env`:
```bash
cp .env.example .env
```
*(Make sure `NEXT_PUBLIC_SERVER_URL` is pointing to your active backend server).*

**2. Install Dependencies**
```bash
npm install
```

**3. Run the Development Server**
```bash
npm run dev
```

The application will now be running at [http://localhost:3000](http://localhost:3000).

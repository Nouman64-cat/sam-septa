# Changelog

All notable changes to the Server application will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## v1.0.1 - 2026-03-25

### Added
- **Award Notice**: Modified the base_url in config.yml to include "Award Notice" in the typeOfNotice filter array.

## v1.0.0 - 2026-03-21

### Added
- **NAICS Code Scraper**: Implemented an automated scraper to retrieve NAICS codes.
- **Database Integration**: Added support for storing NAICS industry codes directly into the database.
- **SAM.gov Filtering**: Enabled users to filter SAM.gov bid scraping using specific NAICS codes.
